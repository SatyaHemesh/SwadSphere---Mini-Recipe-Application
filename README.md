# mini_recipe_app

Mini Recipe App is a Flutter-based mobile application that generates random recipes from Indian and international cuisines. The app displays the recipe name, image, ingredients, and instructions. Users can filter by cuisine and view new recipes with a single tap, making cooking discovery easy and fun.
